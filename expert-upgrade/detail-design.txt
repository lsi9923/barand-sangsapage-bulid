
EXPERT_ART_DIRECTION_V1 — 기존 섹션별 기획과 사용자 추가 지시를 살리는 시각 디렉션:
- 적용 우선순위: 실제 상품 정체성/확인된 사실, 해당 섹션 기획과 사용자가 명시한 수정 조건, 공통 시각 보강 순이다. 자동으로 붙은 번호별 장면 후보나 배경 분류가 실제 기획과 맞지 않으면 사용하지 않는다.
- 카피 윤문과 분량 조절은 신규 기획 단계에 적용한다. 이미지 생성 단계에서는 확정된 해당 섹션 문구를 그대로 쓰고 의미 단위 줄바꿈만 허용한다. 사용자가 문구 수정을 명시한 경우에만 그 부분을 변경한다.
- 상품마다 먼저 실제 첨부 사진의 용도·재질·색·형태를 파악하고 한 가지 촬영 콘셉트를 정한다. 다른 상품의 공간을 이름만 바꿔 재사용하지 않는다. 잘못된 기존 배경 분류는 실제 첨부 상품과 섹션 기획을 기준으로 교정한다.
- 한 상품은 동일한 글꼴 체계·2~3색 팔레트·그리드로 묶고, 장면은 섹션 목적에 맞게 바꾼다. 10개 섹션을 서로 다른 브랜드처럼 꾸미지 않는다.
- 시각적 풍부함은 선명한 제품 디테일, 전경/중경/배경의 깊이, 소재에 맞는 조명, 대담한 크기 대비와 여백으로 만든다. 장식 배지나 의미 없는 영어를 추가하지 않는다.
- 이미지 프롬프트에 주 피사체, 상품이 차지하는 위치/크기, 카메라 거리/각도, 배경 재질/공간, 조명 방향, 카피 안전영역을 구체적으로 설계한다. 이전 섹션과 촬영 목적이 겹치면 거리·각도·배치를 함께 바꾼다.
- 라이딩 장갑은 겨울 야외 이동·정차·그립 디테일, 의류는 착장 실루엣·원단·봉제, 주방도구는 조리·세척·보관처럼 실제 사용 맥락을 고른다. 이는 예시이며 상품마다 새로 판단한다.
- 첫 히어로는 상품 정체성이 바로 읽히는 강한 장면, 기능 섹션은 관찰 가능한 디테일, 사용 섹션은 현실적인 동작, 스펙 섹션은 차분하고 정확한 정보, 마지막은 첫 장면과 다른 거리/각도의 마무리로 구성한다. 기존 섹션 순서와 역할은 유지한다.
- 한글은 단정한 고딕 계열을 기본으로, 부드러운 상품은 곡선이 자연스러운 고딕, 기술/스포츠 상품은 획이 명료한 고딕을 선택한다. 긴 문장에 장식체·극단적으로 좁은 글꼴을 쓰지 않는다. 특정 폰트가 설치되었다거나 정확히 재현된다고 단정하지 않는다.
- 기존 제목/서브 크기와 여백 규칙을 유지하고 굵기·줄간격으로 위계를 만든다. px 값은 원본 캔버스 기준의 참고값이며 모바일 축소 후 판독성을 함께 확인한다. 신규 카피는 제목 1~2줄, 본문 2줄 이내로 기획한다. 확정 카피가 길면 글을 삭제하지 말고 배치를 조정한다. 조사만 다음 줄로 밀리지 않게 하며 글자를 가로 압축하거나 자간을 과하게 벌리지 않는다.
- 밝고 복잡한 사진에는 카피 영역의 명도를 정돈하고, 어두운 사진에는 밝은 글자를 사용한다. 글자가 상품의 핵심 구조를 가리지 않도록 상품 배치부터 조정한다.
- 헤드라인은 실제 이점 한 가지를 짧게 말하고, 서브는 그 이유 또는 사용 상황을 더한다. 같은 명사/이점을 제목·서브·다음 섹션에서 반복하지 않는다. 생성된 이미지에는 확정한 해당 섹션 카피만 넣는다.
- 사용자가 추가한 조건을 항목별로 기존 기획에 연결한다. 상품 사실과 상충하지 않는 조건은 살리고, 중복은 한 번만 표현한다. 디자인 지시를 상품 정보나 이미지 속 문구로 인쇄하지 않는다.
- 출력 직전 상품 외형, 카피 오탈자, 이전 섹션과의 장면 차이, 모바일 가독성을 점검한다. 오류가 있다면 사실이나 스펙을 바꾸지 말고 카피 배치와 장면을 고친다.
